From download to discovery.

Track Lens v0.8.2 is a manually installed Chromium extension for Spotify Web Player and YouTube Music.

Install in Chrome

  1. Download the extension ZIP.
  2. Extract it and move the track-lens folder to a permanent place on your computer.
  3. Open chrome://extensions in Chrome's address bar.
  4. Turn on Developer mode and select Load unpacked.
  5. Select the track-lens folder containing manifest.json. Open Spotify or YouTube Music and play a track.

Official reference: Google's guide to loading unpacked extensions.

Install in Vivaldi desktop

Use the same ZIP and steps, but start in vivaldi://extensions. Official reference: Vivaldi extensions guide.

Vivaldi on Android

Recent Vivaldi Android versions support unpacked extensions. Open Extensions → Manage Extensions → Developer mode → Load unpacked, then select the extracted folder. You may need to enable Desktop site for the YouTube Music and Spotify web players. Compatibility depends on the player version and device. Official mobile guide.

Updating Track Lens

Keep the same folder path.

Download the latest ZIP and replace the files inside the existing track-lens folder, not a new folder with a versioned name. Go to your browser's extensions page, click Reload on Track Lens, then refresh the music tabs.

Unpacked installations do not receive Chrome Web Store automatic updates. Moving the folder can change its extension ID and separate its saved library. Consider Help & Settings → Export backup before major updates.

Using the panel

Click the sun/moon button to switch themes. On desktop, drag the header in any direction or focus the title and use the arrow keys. The mobile strip has its own vertical grip. For Mix Next, open Spotify Radio/Queue or YouTube Music Up Next/Related, then select Find Tracks. Harmonic matches use compatible Camelot keys; other-key recordings appear only in Related tracks and are not harmonic matches. Once the current pool is exhausted, Scan New Tracks collects newly visible songs only. Retry Failed Lookups deliberately rechecks incomplete or failed analyses, in batches of eight; provider rate limits may apply. To dismiss a wrong catalogue review, select Dismiss this suggestion. Its review can be restored for that seed track from the same section.

Privacy and music data

Analysis metadata is sent to Song Finder and sometimes ReccoBeats. The exact mix may need your confirmation; third-party catalogues do not contain every track. For details see our privacy policy.

Report a problem

When reporting an issue, include the browser and version, music platform, extension version, what you expected, and what happened. Don't share exported library backups or account details publicly. Report bugs and feature requests in Track Lens GitHub Issues. The issue tracker is public, so never attach your exported music library, account credentials, browsing history or private screenshots.
