INSTALL IN A FEW STEPS

No store account required.

The beta is installed as an unpacked extension. The process is straightforward, although updates are manual until Track Lens has a store listing.

  1. Download and extract the ZIPKeep the extracted track-lens folder in a permanent location. Avoid moving or renaming it after installation.
  2. Open your browser's extension managerChrome: chrome://extensions · Vivaldi: vivaldi://extensions. Switch on Developer mode.
  3. Choose Load unpackedSelect the extracted track-lens folder (the one containing manifest.json). Open Spotify Web Player or YouTube Music and play a song.
Full installation and update guide ↗

Before you install

  • Track Lens runs only on the supported Spotify and YouTube Music websites, not their native apps.
  • Analysis is provided by Song Finder and, where needed, ReccoBeats. Coverage and scores can vary.
  • Always confirm the exact remix before relying on a suggested key.
  • It doesn't record audio, require a streaming-service login of its own, or include adverts.
Beta software: This is an experimental release. Install unpacked extensions only from sources you trust, and expect occasional manual matching or updates.
